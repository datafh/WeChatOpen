# 微信多开（WeChatOpen）

> 点击即开，多开无忧。一款极简的 Windows 微信多开工具。

**版本：v1.0.1** ｜ **作者：大鱼（数据渔港）** ｜ **联系邮箱：shujuyg@qq.com**

---

## 📖 简介

微信官方客户端默认只允许同时运行一个实例。本工具通过解除微信的实例互斥限制，实现**双击图标即开一个微信，点几次开几个**，无需任何配置。

支持两种发行形态：

| 版本 | 文件 | 大小 | 适合人群 |
|---|---|---|---|
| 免安装便携版 | `WeChatOpen.exe` | 约 8 MB | 追求绿色便携、不想安装软件的用户 |
| 标准安装版 | `微信多开_安装程序.exe` | 约 10 MB | 习惯桌面图标 + 开始菜单 + 规范卸载的用户 |

## 🚀 使用方法

### 方式一：免安装便携版（WeChatOpen.exe）

1. 下载 `WeChatOpen.exe`，放到任意位置（建议桌面）
2. **双击一次 = 打开一个微信**
3. 想开几个就双击几次，每个窗口可登录不同的微信号
4. 不想要了？直接删除文件即可，无残留

### 方式二：标准安装版（微信多开_安装程序.exe）

1. 双击 `微信多开_安装程序.exe` 启动安装向导
2. 阅读并同意软件许可协议，选择安装目录（默认即可）
3. 完成安装后，桌面和开始菜单会出现「微信多开」图标
4. **双击图标一次 = 打开一个微信**，点几次开几个
5. 卸载：`设置 → 应用 → 安装的应用 → 微信多开 → 卸载`，或通过开始菜单快捷方式卸载

## ❓ 常见问题（FAQ）

**Q1：双击后没反应？**
请确认微信 PC 版已正确安装且能正常登录。部分场景下微信正在更新时会出现短暂无响应，等更新完成后再试。

**Q2：杀毒软件提示风险？**
本工具通过系统接口解除微信的单实例限制，不修改微信程序文件、不联网、不收集任何数据。部分杀软对这类工具会误报，添加信任即可。如不放心，可仅在需要时使用。

**Q3：最多能同时开几个微信？**
理论上无上限，实际受内存限制。每个微信实例约占 300~500 MB 内存，建议同时开启不超过 3~5 个。

**Q4：支持微信 3.x 老版本吗？**
当前版本针对微信 4.0 适配。老版本微信如遇异常，可反馈至上方邮箱。

**Q5：多开的微信会被封号吗？**
微信多开属于客户端行为，官方对此没有明确的封禁规则，但请遵守微信使用规范，勿用于营销骚扰等违规场景，风险自担。
